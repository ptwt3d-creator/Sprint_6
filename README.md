# Sprint_6

## Описание locators

- `main_page_locators` - Локаторы главной страницы.

- `order_page_locators` - Локаторы страницы оформления заказа.

## Описание pages 

- `base_page` - Класс и методы для работы с локаторами общих элементов Яндекс Самоката и сами локаторы.

- `main_page` - Класс и методы для работы с локаторами главной страницы из main_page_locators.

- `order_page` - Класс и методы для работы с локаторами страницы заказа из order_page_locators.

## Описание тестов

- `test_accordion_faq_main_page` - Проверки аккордиона FAQ заголовки и описание вопроса.

- `test_navigation_logo` - Проверки навигации по кнопкам-логотипам Яндекс и Самокат.

- `test_order_scooter` - Проверки заказ самоката через кнопки Заказать в шапке\контектсе до успешного заказа.

## Описание дополнительных файлов

- `data.py` - Содержит статические тестовые данные (наборы данных пользователей, адреса и станции метро) для параметризации тестов.

- `requirements.txt` - Список внешних зависимостей и библиотек (классы Selenium, Pytest, Allure), необходимых для работы проекта.
